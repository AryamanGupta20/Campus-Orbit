# Lavender Ticket noticeboard

Use Admin dashboard → Noticeboard to manage the promotion above the student feed.

1. Edit the banner label, headline, description and tags.
2. Choose a right-hand ticket photo (JPG, PNG or WebP, up to 3 MB). The browser resizes the image before saving; a very detailed image may need to be made smaller.
3. Add a short photo description for accessibility.
4. Optionally add both button text and an HTTPS event or registration link.
5. Select Preview banner to review the layout, then Save & publish noticeboard.

The ticket shows the full image without cropping. Event text stays outside the ticket on the left. On phones, the photo moves below the text.

To remove the photo, select Remove current ticket photo and save. To hide the whole banner, turn off Show banner to students and save. Students see published changes after refreshing.

Only administrators can publish noticeboard changes. Uploaded images are visible to signed-in students on the dashboard; do not use private student documents as promotional images.
