# Lavender Ticket noticeboard

Use Admin dashboard → Noticeboard to manage the promotion above the student feed.

1. Edit the banner label, headline, description and tags.
2. Choose a right-hand ticket photo (JPG, PNG or WebP, up to 3 MB). The browser resizes the image before saving; a very detailed image may need to be made smaller.
3. Add a short photo description for accessibility.
4. Optionally add both button text and an HTTPS event or registration link.
5. Select Preview banner to review the layout, then Save & publish noticeboard.

The ticket shows the full image without cropping. Event text stays outside the ticket on the left. On phones, the photo moves below the text.

To remove the photo, select Remove current ticket photo and save. To hide the whole banner, turn off Show banner to students and save. Students see published changes after refreshing.

Only administrators can publish noticeboard changes. Uploaded images are visible to signed-in students on the dashboard; do not use private student documents as promotional images.

## Event promotions

Add event start and end, venue, and an optional registration deadline. All dates use India Standard Time (IST), even on a device in another timezone. Both start and end are required for an event; leave both empty for a permanent announcement. The server hides ended events from students. An already-open feed checks expiry every 30 seconds. Expired events remain available in the admin form for editing.

The registration link is replaced with “Registration closed” at the deadline. This controls the Campus Orbit banner only; an external registration service controls its own acceptance of registrations.

Upload a separate background photo behind the text. A shaded overlay keeps the writing readable. Each image can be replaced or removed independently. Photos are compressed before saving; overly detailed images may need a smaller version. No email reminders or registration system are added by these settings.

## Three event banners

Use Choose banner to edit slots 1, 2 and 3 independently. Existing noticeboard content remains in slot 1. Slots 2 and 3 start hidden, with editable workshop/career starter text. Add confirmed event details and enable them before publishing. Switching slots warns before discarding unsaved changes.

The feed shows only enabled, unexpired banners, ordered by slot. With two or more, students can use arrows, numbered selectors, event cards, View all events, or a horizontal phone swipe. There is no automatic sliding. Each slot keeps separate photos, dates, venue and destination. Hide a slot using Show banner to students.
