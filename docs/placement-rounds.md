# Placement Round Practice

Placement Desk no longer links to Career Roadmaps. The old career continuation card is removed. Existing stored career data is kept; College Courses degree roadmaps are unchanged.

The Round practice tab offers aptitude/reasoning, technical, debugging/troubleshooting, project discussion and HR/communication. Technical prompts use the selected role. There is one debugging scenario for each of the 15 roles, five aptitude prompts, four project prompts and four HR prompts. Technical content reuses the existing 29 skill questions. All prompts and guides have English and Hinglish versions.

Students browse or practise one question at a time. Answers must be entered before the guide is revealed. Self-review criteria vary for aptitude and debugging. The selected round, typed answers, reveal state and self-review checks persist privately through the existing state endpoint. No AI grading, code execution or claim about a particular company's actual rounds.

Tests cover every role's debugging scenario, switching rounds and languages, answer preservation, restored selection and server option validation. Visual phone/browser checks remain unverified because the earlier automatic browser approval review hit a usage limit.
