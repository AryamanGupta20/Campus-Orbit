# Study upgrades

Exam Preparation appears after choosing a course. Students type or paste dates, review them, add syllabus units, choose readiness and half-hour estimates, and build a daily plan. The planner works from today, keeps completed task IDs, leaves exam days free, and shows work that cannot fit. Up to ten subjects, twelve units each and 180 days. Past-paper questions are typed, private, and shown alongside matching practice tasks.

Existing catalogue playlists are matched by subject and language. Other subjects get a YouTube search link. No YouTube API, automatic playlist import, OCR or file reading is included. Check syllabus coverage.

Career checkpoints save a project link, personal contribution notes and five self-checks. These are student claims, not verified achievements. Resume check gives missing-field and link feedback plus project and viva prompts; it is not an ATS score or hiring guarantee.

All fields use the existing private versioned state endpoint. Older clients preserve study and evidence fields. Shared portfolios exclude study, resume and checkpoint data.

Tests cover scheduling capacity and dates, completion and rescheduling, screen actions, backend validation and private data isolation. Local browser previews use fictional state; they do not prove production account persistence.
